# HAKIM — الوكيل الطبي والعلمي (الإصدار 1.5.2)

أداة تثقيف ودعم بحثي بست لغات (العربية، English، עברית، Deutsch، Français، Español). ليست جهازاً طبياً ولا أداة تشخيص، ولا تغني عن مختص مرخّص.

## ماذا تفعل
- **بحث علمي مدمج** من مصادر مجانية: Europe PMC وPubMed وOpenAlex وClinicalTrials.gov. تُترجم الأسئلة العربية والعبرية وغيرها إلى مصطلحات إنجليزية قبل البحث، وتُستبعد المقالات المسحوبة.
- **مونوغراف مبني على مراجع مسترجعة فعلاً:** التعرف على اسم النبتة أو الزيت (عربي/علمي/إنجليزي) والتحقق من الاسم العلمي عبر GBIF، ثم كتابة تقرير يشير إلى المراجع بالأرقام. قائمة المراجع تأتي من السجلات المسترجعة وليست من كتابة النموذج.
- **ترويسة وطباعة:** ترويسة حكيم، أو ترويسة المستخدم (شعار واسم وتفاصيل)، أو ورق مروّس جاهز بهوامش فارغة؛ كل صفحة أو الأولى فقط؛ A4 أو Letter.
- **تحليل سريري وعصف ذهني** مع خيار ربطه بدراسات منشورة، و**مقارنة تقارير الأشعة**، و**تحليل نصوص المحاضرات**.
- **مراجعة تعليمية لصور الأشعة** (JPEG/PNG، حتى 4 صور).

## الملفات
| الملف | الدور |
|---|---|
| `app.py` | الخادم (FastAPI) واتصال Gemini ومحرك الأدلة |
| `hakim-ui.html` | الواجهة (إن غاب فيُستعمل `index.html`) |
| `requirements.txt` | الحزم: fastapi وuvicorn[standard] وpython-dotenv وpydantic وgoogle-genai |

## النشر على Render
1. أنشئ **Web Service** من هذا المستودع (وليس Static Site) واختر الفرع الذي تعمل عليه.
2. Build: `pip install -r requirements.txt` — Start: `uvicorn app:app --host 0.0.0.0 --port $PORT`
3. في **Environment** أضف:
   - `GEMINI_API_KEY` (مطلوب) — لا تضعه أبداً في HTML أو GitHub.
   - `GEMINI_MODEL` (اختياري)، `CONTACT_EMAIL` (اختياري، يحسّن تعامل OpenAlex)، `NCBI_API_KEY` (اختياري، يرفع حد PubMed).
4. بعد كل رفع للملفات اضغط **Manual Deploy ← Deploy latest commit** (إن لم يكن النشر التلقائي مفعّلاً).

## التحقق بعد النشر
- أسفل الصفحة يظهر `UI 1.5.2 · API 1.5.2`.
- `/api/health` يعرض الإصدار واسم ملف الواجهة وحجمه.
- `/api/sources-status` يفحص اتصال كل مصدر.
- `/api/query-plan?q=رعشة اليدين` يعرض كيف حُوّل السؤال إلى مصطلحات بحث (دون استدعاء قواعد البيانات).

## حدود يجب معرفتها
- الطبقة المجانية من Gemini لها حد طلبات؛ قد تظهر رسالة «حد الطلبات»، فانتظر نصف دقيقة.
- خدمة Render المجانية تنام عند الخمول وقد تحتاج نحو دقيقة للاستيقاظ.
- البحث لا يضمن اكتشاف كل الأدلة، وظهور دراسة في النتائج ليس حكماً على جودتها. راجع تصميم الدراسة وحجم العينة والقيود قبل الاعتماد عليها.
- الأسماء الناتجة (خاصة العربية) قابلة للتعديل يدوياً ويجب مراجعتها قبل النشر.
- المونوغراف مسودة بمساعدة الذكاء الاصطناعي: راجع المصادر الأصلية قبل أي استعمال.
