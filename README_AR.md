# الوكيل الطبي والعلمي — المرحلة 2 (محرك خلفي أولي)

## ما الذي يضيفه هذا الإصدار؟
- واجهة عربية محلية تُخدم من التطبيق نفسه.
- واجهة API خلفية تستدعي نموذجًا لغويًا عند توفير مفتاح API.
- مسارات منفصلة للعصف الذهني السريري، ومقارنة نص تقرير الأشعة بالملاحظات المكتوبة، وتحليل تفريغ المحاضرة، وطلب بحث علمي.
- لا يحفظ التطبيق الحالات في قاعدة بيانات، ولا يكتب محتوى الطلبات إلى ملفات.
- ضوابط صريحة ضد اختلاق المراجع والادعاء بقراءة صور أو فيديو لم تُعالج فعليًا.

## متطلبات مهمة
1. تحتاج إلى Python 3.10 أو أحدث.
2. تحتاج إلى مفتاح API من مزود النموذج. اشتراك ChatGPT لا يعني تلقائيًا وجود رصيد API؛ قد تكون هناك تكلفة استخدام منفصلة.
3. المفتاح يبقى في ملف `.env` على جهازك ولا يوضع في HTML ولا ترسله في المحادثة.
4. البحث عبر الويب معطل افتراضيًا. يمكن تفعيله بتغيير `ENABLE_WEB_SEARCH=true`، وقد يزيد التكلفة؛ يجب فحص المصادر الناتجة بنفسك.

## التشغيل على Windows
1. فك ضغط الملف إلى مجلد عادي.
2. انقر مرتين على `start_windows.bat`.
3. في المرة الأولى، افتح ملف `.env` باستخدام Notepad وأضف مفتاح API مكان النص التجريبي، ثم احفظه.
4. أوقف الخادم في نافذة الأوامر بـ Ctrl+C ثم شغّل `start_windows.bat` مرة أخرى.
5. افتح `http://127.0.0.1:8000` في Chrome أو أي متصفح حديث.

## التشغيل على macOS / Linux
شغّل `start_mac_linux.sh` من الطرفية. عدّل `.env` كما سبق ثم أعد تشغيل الخادم.

## اختبار الخدمة
بعد تشغيل الخادم، افتح `http://127.0.0.1:8000/api/health`. ستظهر حالة الخادم وما إذا كان المفتاح مضبوطًا.

## حدود هذه المرحلة
- هذه نسخة أولية وليست جهازًا طبيًا معتمدًا، ولا تصلح لاتخاذ قرارات علاجية مستقلة.
- لا يوجد تحليل فعلي لصور الأشعة أو ملفات DICOM، ولا رفع/استخراج تلقائي لمحتوى PDF أو Word، ولا تفريغ تلقائي لفيديو YouTube. وحدة التصوير تقارن النصوص التي تدخلها فقط.
- لا توجد قاعدة بيانات أو حسابات مستخدمين أو تشفير تخزين؛ لذلك لا تدخل بيانات تعريفية أو سجلات مرضى حقيقية. أبقِ الاستخدام في بيانات تعليمية/منزوعة الهوية إلى أن تُنفذ مراجعة أمنية وخصوصية مناسبة.
- لا توجد أداة بحث طبي مستقلة مهيأة بمصادر مُعتمدة أو إدارة مراجع. تفعيل web search ليس بديلًا عن التحقق من المصادر الأصلية.
- مفتاح API والطلبات قد تخضع لسياسات مزود الخدمة وشروطه. راجعها قبل إدخال أي بيانات حساسة.

## حل المشكلات
- `api_key_configured: false`: عدّل `.env` ثم أعد تشغيل الخادم.
- `تعذر إكمال الطلب`: افحص اتصال الإنترنت، وصلاحية المفتاح، وتوفر الرصيد/الحدود في حساب API.
- إذا لم يعمل ملف التشغيل، تأكد من تثبيت Python 3.10+ وأنه متاح من سطر الأوامر.
