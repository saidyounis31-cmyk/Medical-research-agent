# الوكيل الطبي والعلمي — الإصدار 2.1

## الجديد في هذا الإصدار
- بحث مباشر في فهرس Europe PMC عبر نقطة النهاية `/api/literature-search`.
- البحث العلمي في Europe PMC لا يحتاج إلى مفتاح API مدفوع؛ تظهر سجلات المقالات وروابطها وملخصاتها عندما تكون متاحة.
- خيار لتصفية النتائج إلى المقالات المفتوحة الوصول، وتحديد 5 أو 10 أو 20 نتيجة.
- تبقى وحدات التحليل السريري ومقارنة التقارير وتحليل المحاضرات معتمدة على محرك الذكاء الاصطناعي، وتتطلب مفتاح مزوّد API.
- لا يحفظ التطبيق الحالات في قاعدة بيانات، ولا يكتب محتوى الطلبات إلى ملفات.

## النشر على Render عبر GitHub
1. استبدل ملفي `app.py` و`index.html` في مستودع GitHub بالنسختين المرفقتين في هذا الإصدار.
2. تأكد أن `requirements.txt` يتضمن: `fastapi`, `uvicorn[standard]`, `openai`, `python-dotenv`.
3. احفظ التغييرات في GitHub؛ إذا كان Render مربوطًا بالمستودع مع النشر التلقائي فسيبدأ النشر. وإلا اضغط Manual Deploy في Render.
4. بعد اكتمال النشر، افتح موقعك وانتقل إلى «البحث العلمي»، ثم جرّب البحث عن `asthma randomized trial`.
5. يمكن فحص حالة الخادم من `/api/health`.

## ما يعمل دون مفتاح AI؟
البحث المباشر في فهرس Europe PMC فقط. أما صياغة تحليل ذكي أو توليف نقدي للنتائج عبر نموذج لغوي فتتطلب مفتاح API وإعداداته على الخادم. لا تضع المفتاح في HTML أو GitHub؛ أضفه فقط في Environment Variables على Render إذا قررت تفعيل النموذج، مع العلم أن تكلفة API منفصلة عن اشتراك ChatGPT.

## حدود البحث
- Europe PMC فهرس للأدبيات العلمية، وليس حكمًا على جودة الأدلة ولا توصية علاجية.
- قد لا يتوفر ملخص أو نص كامل لكل سجل. راجع المقال الأصلي، وتصميم الدراسة، وحجم العينة، والنتائج، والقيود، والتمويل.
- صياغة الاستعلام تؤثر في النتائج؛ استخدم مصطلحات إنجليزية ومرادفات طبية، ثم راجع النتائج يدويًا.
- البحث لا يضمن اكتشاف كل الأدلة ذات الصلة، ولا يغني عن مراجعة قواعد ومصادر إضافية عند الحاجة.

## الخصوصية والسلامة
- لا تدخل أسماء المرضى أو أرقام الهوية أو عناوينهم أو بيانات تعريفية.
- الملفات التي تختارها في وحدات التصوير والحالة تعرض أسماءها محليًا فقط؛ لا تُرفع ولا تُحلّل محتوياتها في هذه النسخة.
- هذا نموذج أولي للتثقيف والدعم البحثي وليس جهازًا طبيًا معتمدًا أو بديلًا عن اختصاصي مرخص.
- لا تؤخر الرعاية العاجلة ولا توقف دواءً موصوفًا بناءً على مخرجاته.

## ملاحظة تقنية
البحث يستدعي واجهة Europe PMC من الخادم عبر اتصال HTTPS. لا يُطلب مفتاح Europe PMC لهذا الاستخدام. إذا تعذر الاتصال، تظهر رسالة خطأ عربية ويمكن إعادة المحاولة لاحقًا.
